# Sukko Scoop Bucket

Scoop manifests for [Sukko](https://github.com/sukko-dev/sukko) tools.

```powershell
scoop bucket add sukko https://github.com/sukko-dev/scoop-bucket
scoop install sukko
```

Manifests in this repository are generated and updated automatically by the
[cli](https://github.com/sukko-dev/cli) release pipeline — do not edit by hand.
